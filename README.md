# pi-multi-agent

一款为 [pi 编码智能体](https://github.com/earendil-works/pi) 设计的多智能体编排扩展。
使用专门化的智能体流水线分解复杂任务，全部中文界面，实时显示 Todo 列表和思考过程。

## 架构

```
用户任务
    │
    ▼
┌──────────────────────────────────────┐
│ 主智能体 (轻量模型 flash)            │
│ • 分析和分解任务                     │
│ • 判断是否需要子智能体               │
│ • 显示 Todo 列表和思考过程           │
└──────────────┬───────────────────────┘
               │
               ▼
┌──────────────────────────────────────┐
│ 子智能体 (x3, 可配置模型)           │
│ • 并行或串行执行子任务               │
│ • 每个有独立上下文                   │
│ • 实时更新 Todo 状态和思考步骤       │
└──────────────┬───────────────────────┘
               │
               ▼
┌──────────────────────────────────────┐
│ 最终智能体 (专业模型 pro)            │
│ • 合成所有结果                       │
│ • 生成连贯的最终输出                 │
│ • 展示完整的推理过程                 │
└──────────────────────────────────────┘
```

## 功能特点

- **任务分解**：主智能体（flash 快速模型）分析和分解复杂任务
- **并行执行**：最多 3 个子智能体可并行运行（可配置）
- **灵活配置**：基于 TUI 的中文配置界面，支持模型和思考级别设置
- **Todo 列表显示**：实时展示每个智能体的待办事项及完成状态
- **思考过程显示**：完整记录并展示每个智能体的推理步骤
- **费用追踪**：查看每个智能体的 Token 使用量和费用
- **流式输出**：智能体工作时实时更新

## 模型说明

本扩展仅支持 **两种模型**，通过 `/multi-agent` 命令配置：

| 模型 | 标识 | 说明 |
|------|------|------|
| **Flash (快速)** | `flash` | 轻量快速模型，适合任务分解和简单执行 |
| **Pro (专业)** | `pro` | 强大专业模型，适合复杂推理和代码生成 |

**默认配置：**
- 主智能体：`flash`（快速分解任务）
- 子智能体：`pro`（专业执行子任务）
- 最终智能体：`pro`（专业合成结果）

## 安装

### 方式一：通过 npm 安装（推荐）

```bash
cd pi-multi-agent
npm install
```

安装后脚本会自动复制扩展到 `~/.pi/agent/extensions/pi-multi-agent/`。

### 方式二：手动安装

```bash
# 创建扩展目录
mkdir -p ~/.pi/agent/extensions/pi-multi-agent

# 复制源文件
cp -r src/* ~/.pi/agent/extensions/pi-multi-agent/
cp package.json ~/.pi/agent/extensions/pi-multi-agent/

# 安装依赖
cd ~/.pi/agent/extensions/pi-multi-agent
npm install
```

### 方式三：通过 pi settings.json

在 `~/.pi/settings.json` 或 `.pi/settings.json` 中添加：

```json
{
  "packages": [
    "npm:pi-multi-agent@1.0.0"
  ]
}
```

## 使用方法

### 1. 配置

安装后，重启 pi（或运行 `/reload`），然后配置扩展：

```
/multi-agent
```

这会打开一个中文 TUI 配置界面，您可以设置：
- **主智能体**：模型（flash/pro）和思考级别
- **子智能体 1-3**：每个子智能体的模型和思考级别
- **最终智能体**：模型和思考级别
- **高级设置**：并行/串行执行、最大 Token 数

### 2. 在对话中使用

当您有复杂任务时，告诉 LLM 使用 multi_agent 工具：

> "使用 multi_agent 重构认证系统"

或者 LLM 可以自主决定对复杂任务使用此工具。

流水线将：
1. **主智能体** 分析您的任务并创建子任务（显示 Todo 列表和思考过程）
2. **子智能体** 执行每个子任务（实时更新 Todo 状态）
3. **最终智能体** 将所有内容合成为全面的响应

## 配置参考

| 设置项 | 默认值 | 说明 |
|---------|---------|-------------|
| 主智能体模型 | flash | 任务分解使用的模型 |
| 主智能体思考级别 | 高 | 主智能体的推理深度 |
| 子智能体模型 | pro | 子任务执行的模型 |
| 子智能体思考级别 | 高 | 子智能体的推理深度 |
| 最终智能体模型 | pro | 结果合成的模型 |
| 最终智能体思考级别 | 最高 | 最终智能体的推理深度 |
| 并行执行 | 是 | 子智能体是否并行运行 |
| 最大 Token | 8192 | 每个智能体响应的最大 Token 数 |

## 思考级别

| 级别 | 说明 |
|-------|-------------|
| 关闭 | 不进行扩展思考 |
| 最低 | 最少的推理步骤 |
| 低 | 较低的推理力度 |
| 中等 | 平衡的推理 |
| 高 | 深入的推理 |
| 非常高 | 非常深入的推理 |
| 最高 | 最大推理深度 |

## 命令

| 命令 | 别名 | 说明 |
|---------|-------|-------------|
| `/multi-agent` | `/ma` | 打开配置界面 |

## 工具

扩展注册了 `multi_agent` 工具，LLM 可以调用：

```
multi_agent(task: string)
```

## Todo 列表和思考过程

扩展在执行过程中会实时显示：

- **📋 待办列表 (Todo List)**：显示所有子任务及其状态（⬜待办 → 🔄执行中 → ✅完成/❌失败）
- **💭 思考过程 (Thinking Process)**：记录每个智能体的推理步骤和时间戳

您可以在结果视图中按 `Ctrl+O` 展开查看详细内容。
